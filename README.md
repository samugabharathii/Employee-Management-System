# Employee Management System

A full-stack web application developed to manage employee records efficiently using Spring Boot, Angular, and MySQL.

## Technologies Used

**Backend:** Java, Spring Boot, Spring Data JPA, Maven  
**Frontend:** Angular, TypeScript, HTML, CSS  
**Database:** MySQL  
**API Testing:** Angular UI

## Features

- Add new employees
- View all employee records
- Update employee details
- Delete employee records
- Search employees
- Filter by department and status
- Sort and paginate employee records
- Form validation
- Duplicate email validation

## Project Structure

- `Backend` – Spring Boot REST API and database operations
- `Frontend` – Angular user interface

## Database

MySQL is used to store employee information, including employee name, email, department, salary, joining date, and employment status.

## How to Run

**Backend**
1. Open the Backend project in Eclipse.
2. Configure MySQL database credentials.
3. Run the Spring Boot application.

**Frontend**
1. Open the Frontend folder in VS Code.
2. Run `npm install`.
3. Run `ng serve -o`.
4. Open `http://localhost:4200/` in your browser.
